{{- else if eq $auth "false" }}

ACTION NEEDED: contentSource has no auth: block and server.insecureNoAuth is
false. `mk mcp serve-http` REFUSES to bind 0.0.0.0 without authentication,
so this pod will exit at startup. Either:

  - add an auth: block (OIDC providers and rules) to contentSource.config (or .raw), or
  - set server.insecureNoAuth=true when a gateway authenticates every request
    (or put `allow_unauthenticated: true` in the auth: block).

See the chart README, section "Authentication".
